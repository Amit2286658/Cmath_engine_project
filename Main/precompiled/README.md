# Precompiled Engine & Standard Library (`precompiled/`)

Drop-in precompiled artifacts for Android apps (`Ecalc`). The native C11 engine binary (`libmathengine.so`) and the precompiled standard library image (`stdlib.mathc`) are stored separately here and bundled directly into the Android app so startup requires **zero network lookups** for the core engine or standard library.

| Path | Contents | Target Location in Android App (`Ecalc`) |
| :--- | :--- | :--- |
| `arm64-v8a/libmathengine.so` | Math Engine (MEP) shared library — Android bionic, API 24+, ARM64 (`aarch64`). Exports both the `eng_*` C API and `Java_com_mathengine_MathEngineBridge_*` JNI entry points. | `app/src/main/jniLibs/arm64-v8a/libmathengine.so` |
| `stdlib.mathc` | Precompiled 18-module `.mathc` binary image (`244,423` bytes) generated by `mathc` from `Library/*.math`. Validated and loaded in $O(1)$ `memcpy` time via `nativeCreateBlank()` + `nativeLoadMathc()`. | `app/src/main/assets/precompiled/stdlib.mathc` |
| `VERSION.txt` | Single-line engine & stdlib release version (`1.0.0`). | Reference metadata |

## Rebuilding Both Precompiled Artifacts

1. **Rebuild `stdlib.mathc` (after editing `Library/*.math`):**
   ```console
   $ make stdlib
   ```
   This compiles and links `Library/*.math` into `Library/stdlib.mathc`, copies it to `precompiled/stdlib.mathc`, and updates `Core/Headers/stdlib_precompiled.h` for the host CLI test suite.

2. **Rebuild `arm64-v8a/libmathengine.so` (after editing `Core/`):**
   ```console
   $ ANDROID_NDK_TOOLCHAIN_BIN=<ndk>/toolchains/llvm/prebuilt/<host>/bin \
         tools/build_android_arm64.sh
   ```
   The script compiles `Core/` with `-DMATH_ENGINE_SEPARATE_STDLIB=1` (omitting the embedded `k_stdlib_mathc` C array from `.rodata` to keep the `.so` lean), strips symbols with `llvm-strip`, writes `precompiled/arm64-v8a/libmathengine.so`, and syncs `precompiled/stdlib.mathc`.
